## 🎨 About

This theme brings the soothing pastel colors of [Catppuccin](https://github.com/catppuccin/catppuccin) to your OneCommander experience. Featuring the Mocha flavor with Mauve accents, it provides a cohesive and aesthetically pleasing dark theme that reduces eye strain while maintaining functionality.

## 🚀 Installation

### Quick Setup

1. **Download** the theme files
2. **Copy** both the `Themes` and `Resources` folders
3. **Paste** them in the root of your OneCommander installation directory

### Finding OneCommander Root Directory

To locate your OneCommander installation:

1. Open OneCommander
2. Click the **"About Me"** button located at the bottom-left, next to the settings
3. Click **"Exe location"** to open the installation folder
4. Place the `Themes` and `Resources` folders in this directory

## 🎨 Customization

The theme offers some customization options:

- **Accent Color**: Adjustable in `Catppuccin.xaml` at line 56 under "AccentBrushForced"
- **Remove Accent Override**: Delete the "AccentBrushForced" line to allow OneCommander's color picker to control the accent color
- **Personal Touch**: Feel free to edit colors and styles to match your preferences
